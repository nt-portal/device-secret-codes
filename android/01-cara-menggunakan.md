# Cara Menggunakan Kode Dial di Android 📞

Bingung mengapa kode terkadang berfungsi dan terkadang tidak? Bagian ini akan menjelaskannya secara sederhana dan praktis.

## Dua Jenis Kode

**A. Kode Internal Android (`*#*#XXXX#*#*` / `*#XXXX#`)**
Diproses langsung oleh sistem Android dan aplikasi Telepon bawaan. Kelebihannya, begitu karakter terakhir diketik — menu akan langsung terbuka secara otomatis tanpa perlu menekan tombol Panggil. Tidak memerlukan kartu SIM atau sinyal. Contoh sederhana: ketik `*#06#`, maka IMEI akan langsung ditampilkan.

**B. Kode MMI / USSD Operator (`*...#` / `*#...#`)**
Kode jenis ini dikirim ke jaringan operator (GSM/4G/5G). Setelah mengetik kodenya, Anda wajib menekan tombol **Panggil** (warna hijau) untuk memprosesnya. Contoh: `*#21#` → tekan Panggil.

## Langkah-Langkah Penggunaan

```text
Buka Telepon bawaan → Keypad → Ketik kode → Terbuka otomatis / tekan Panggil
```

1. **Gunakan aplikasi Telepon bawaan** — seperti Google Phone, Samsung Phone, atau MIUI Dialer. Hindari aplikasi pihak ketiga seperti Truecaller atau WhatsApp.
2. Ketik kode dengan tepat, perhatikan urutan `*` dan `#` agar tidak tertukar.
3. Jika setelah mengetik karakter terakhir tidak ada respons, kemungkinan kode tersebut diblokir oleh vendor atau memang tidak didukung di perangkat Anda.

> Tips: Jangan menekan Panggil untuk kode internal yang belum Anda pahami fungsinya.
