# Tes Hardware Android 🛠️

Bagian ini sangat berguna ketika Anda ingin membeli HP bekas — semua komponen fisik dapat diperiksa tanpa perlu membongkar perangkat.

| Kode | Komponen | Cara pengujian |
|---|---|---|
| `*#*#2664#*#*` | Touchscreen | Usap seluruh layar, cari area yang tidak responsif |
| `*#*#2663#*#*` | Firmware touch | Melihat versi IC touch |
| `*#*#0842#*#*` | Getar & backlight | Memeriksa getaran dan kecerahan layar |
| `*#*#0673#*#*` / `*#*#0289#*#*` | Speaker | Memutar nada uji |
| `*#*#0283#*#*` | Audio loopback | Suara dari mic langsung diteruskan ke earpiece |
| `*#*#0588#*#*` | Proximity sensor | Tutup bagian earpiece, layar seharusnya mati |
| `*#*#232339#*#*` | Wi-Fi | Tes Tx/Rx |
| `*#*#232331#*#*` | Bluetooth | Tes radio Bluetooth |
| `*#*#1575#*#*` | GPS | Tes penguncian satelit |
| `*#*#34971539#*#*` | Firmware kamera | Melihat vendor sensor (IMX / ISOCELL) |
