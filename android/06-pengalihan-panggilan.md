# Pengalihan Panggilan Android 📞

Semua kode di sini diproses oleh operator, jadi jangan lupa menekan **Panggil** setelah mengetik kode.

| Kode | Fungsi |
|---|---|
| `*#21#` | Memeriksa pengalihan semua panggilan |
| `*#61#` | Memeriksa pengalihan saat tidak dijawab |
| `*#62#` | Memeriksa pengalihan saat HP mati / tidak ada sinyal |
| `*#67#` | Memeriksa pengalihan saat sibuk |
| `*#004#` | Memeriksa semua pengalihan bersyarat sekaligus |
| `*#002#` | Memeriksa semua pengalihan |
| `##002#` | **Menghapus semua pengalihan** |
| `*#43#` | Memeriksa call waiting |
| `*43#` / `#43#` | Mengaktifkan / menonaktifkan call waiting |

**Curiga disadap?** Coba ketik `*#21#` → Panggil. Jika muncul status *Forwarded* ke nomor asing yang bukan voicemail operator → segera ketik `##002#` → Panggil. Penjelasan lengkap tersedia di [umum/01-kode-ussd-mmi-universal.md](../umum/01-kode-ussd-mmi-universal.md).
