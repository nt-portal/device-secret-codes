# Kode Berisiko Tinggi di Android ⚠️

> Bagian ini jangan dicoba secara iseng di HP utama — berisiko menghapus data atau menyebabkan bootloop. Pastikan sudah melakukan backup terlebih dahulu!

| Kode | Tingkat risiko | Dampak |
|---|---|---|
| `*#*#7780#*#*` | Tinggi | Factory reset — menghapus akun dan aplikasi (file internal kadang masih tersisa) |
| `*2767*3855#` | **Kritis** | Format total firmware dan storage tanpa konfirmasi (Samsung lama) |
| `*#0808#` | Sedang | Kesalahan pengaturan USB → HP tidak terbaca di PC |
| `*#9090#` | Sedang | Kesalahan pengaturan diag → dapat menyebabkan bootloop / modem error |
| `*#2263#` | Sedang | Kesalahan penguncian band → sinyal hilang |

Jika tidak sengaja masuk ke menu yang tidak dikenal, segera tekan **Back/Home** — jangan menekan *Apply/Format/Reset*.
