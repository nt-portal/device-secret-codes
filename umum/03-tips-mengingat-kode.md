# Tips Mengingat Kode Agar Mudah Diingat ✨🧠

> Kodenya memang banyak — namun jika memahami polanya, akan jauh lebih mudah untuk diingat.

---

## Pola Dasar (Menghafal Ini = Menguasai 80% Kode)

```
*#06#  = IMEI              → "06 = Oh Enam = Oh IMEI"
*#21#  = cek pengalihan    → "21 = Dua-satu = Dua kali dialihkan? cek 21"
*#62#  = tidak terjangkau  → "62 = kode negara Indonesia = HP mati di luar jangkauan"
*#67#  = sibuk             → "67 = 6-7 sibuk menolak telepon"
##002# = hapus semua       → "002 = NOL-kan semua pengalihan"
*3001#12345#* = Field Test iPhone → "3001 = Tiga-nol-nol-satu = Test"
```

## Pengelompokan Agar Lebih Mudah

- **Grup 06/07 (Identitas):** `*#06#` IMEI, `*#07#` SAR — "06-07 berurutan, identitas perangkat"
- **Grup 21/61/62/67 (Pengalihan):** "21 cek semua, 61 tidak dijawab, 62 tidak terjangkau, 67 sibuk" — urutan 21 → 61 → 62 → 67
- **Grup 43 (Tunggu):** `*#43#` = "43 = For Three? For waiting"
- **Grup Android `*#*#...#*#*`:** Ingat **4636 = INFO**, **6484 = CIT**, **2846579 = PROJECT** — polanya bintang-pagar-bintang-pagar + angka + pagar-bintang-pagar-bintang.

## Trik Praktis

1. **Simpan sebagai kontak:** Buat kontak bernama `Cek Alihan` dengan nomor `*#21#`, dan seterusnya. Tinggal ketuk kontak → Panggil.
2. **Screenshot cheat-sheet** dari [umum/01-kode-ussd-mmi-universal.md](01-kode-ussd-mmi-universal.md) — jadikan wallpaper lockscreen.
3. **Latihan seminggu sekali:** ketik `*#21#` → `##002#` → `*#06#` — hanya 30 detik, lama-lama akan hafal dengan sendirinya.
