# Umum — Tips Menghafal Kode Biar Mudah Diingat ✨

> Semua kode di repo ini dibuat nempel di otak pakai mnemonic, cerita, dan pola.

---

## 1. Pola Dasar (Hafal Ini Dulu = 80% Kode Kuasai)

```
*#06#  = IMEI        → "06 = O6 = Oh Enam = Oh IMEI"
*#21#  = alihan all  → "21 = Dua-satu = Dua kali dialihkan? cek 21"
*#62#  = tidak terjangkau → "62 = kode negara Indonesia = HP mati di luar jangkauan"
*#67#  = sibuk        → "67 = 6-7 sibuk menolak telpon"
##002# = hapus semua  → "002 = nol-nol dua = NOL-kan semua alihan"
*3001#12345#* = iPhone Field Test → "3001 = 30-01 = Tiga-nol-nol-satu = Test"
```

## 2. Mnemonic Grup

- **Grup 06/07 (Identitas):** `*#06#` IMEI, `*#07#` SAR — "06-07 urut, identitas HP"
- **Grup 21/61/62/67 (Alihan):** "21 cek semua, 61 tak-jawab, 62 tak-jangkau, 67 sibuk" → urut 21 → 61 → 62 → 67
- **Grup 43 (Tunggu):** `*#43#` = "43 = For Three? For waiting — call waiting"
- **Grup Android `*#*#...#*#*`:** Ingat **4636 = INFO**, **6484 = CIT**, **2846579 = PROJECT** — ketik bintang-pagar-bintang-pagar + angka + pagar-bintang-pagar-bintang.

## 3. Trik Praktis

1. **Simpan 5 kode favorit** sebagai kontak: Nama `Cek Alihan` nomor `*#21#`, dst. Tinggal tap kontak → Panggil.
2. **Screenshot cheat-sheet** dari halaman [umum/01-kode-ussd-mmi-universal.md](01-kode-ussd-mmi-universal.md) — jadikan wallpaper lockscreen.
3. **Latihan 1x seminggu:** ketik `*#21#` → `##002#` → `*#06#` — 30 detik hafal permanen.
