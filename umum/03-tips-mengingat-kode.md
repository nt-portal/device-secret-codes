# Tips Menghafal Kode Biar Nempel di Kepala ✨🧠

> Jujur aja, kodenya banyak — tapi kalau tau polanya, gampang banget diingat.

---

## Pola Dasar (Hafal Ini Dulu = 80% Kuasai)

```
*#06#  = IMEI        → "06 = Oh Enam = Oh IMEI"
*#21#  = cek alihan  → "21 = Dua-satu = Dua kali dialihkan? cek 21"
*#62#  = nggak terjangkau → "62 = kode negara Indonesia = HP mati di luar jangkauan"
*#67#  = sibuk        → "67 = 6-7 sibuk nolak telpon"
##002# = hapus semua  → "002 = NOL-kan semua alihan"
*3001#12345#* = Field Test iPhone → "3001 = Tiga-nol-nol-satu = Test"
```

## Grup Biar Gampang

- **Grup 06/07 (Identitas):** `*#06#` IMEI, `*#07#` SAR — "06-07 urut, identitas HP"
- **Grup 21/61/62/67 (Alihan):** "21 cek semua, 61 tak-jawab, 62 tak-jangkau, 67 sibuk" — urut 21 → 61 → 62 → 67
- **Grup 43 (Tunggu):** `*#43#` = "43 = For Three? For waiting"
- **Grup Android `*#*#...#*#*`:** Ingat **4636 = INFO**, **6484 = CIT**, **2846579 = PROJECT** — polanya bintang-pagar-bintang-pagar + angka + pagar-bintang-pagar-bintang.

## Trik Praktis

1. **Simpan sebagai kontak:** Bikin kontak `Cek Alihan` nomornya `*#21#`, dst. Tinggal tap kontak → Panggil.
2. **Screenshot cheat-sheet** dari [umum/01-kode-ussd-mmi-universal.md](01-kode-ussd-mmi-universal.md) — jadiin wallpaper lockscreen.
3. **Latihan seminggu sekali:** ketik `*#21#` → `##002#` → `*#06#` — 30 detik aja, lama-lama hafal permanen.
